# SLG-MOEA

This repository provides the core implementation of SLG-MOEA proposed in our paper.

## Requirements
MATLAB R2023a or a compatible version.

## Example
A runnable example using the Australian dataset is provided.

Run in MATLAB:

SLG_MOEA_Main

or from the command line:

matlab -batch "run('SLG_MOEA_Main.m')"

The output files are saved in:

results/australian/
